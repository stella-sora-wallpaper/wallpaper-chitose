# 《星塔旅人》资源与互动调研

更新：2026-09-10

## 结论

《星塔旅人》存在与《蔚蓝档案》记忆大厅“体验上相近”的角色关系内容，但目前没有在
官方页面确认一个同名“记忆大厅”系统。官方宣发明确提到与旅人签订契约、使用“心链”
传递心意，以及邀请心仪旅人同游；社区剧情整理则把可见内容分为旅人剧情/心链、通讯、
邀约、星塔事件剧情和秘纹剧情。因此千都世壁纸可以借鉴“角色待机 + 触发对话/动作”的
形式，但项目文案不应直接声称存在官方“记忆大厅”。

## 互动与动作

- 官方角色页列出千都世（Chitose）的中/日文角色信息，证明角色是官网公开内容的一部分。
- 官方新闻将“心链”和“邀请同游”作为角色关系体验描述，说明对话、邀约和关系推进是
  游戏设计的一部分。
- 社区实况的标题和目录包含通讯、邀约、好感度剧情等类别，可作为人工整理剧情入口的线索，
  但不是可再分发资源授权。
- Live2DHub 的实际导出讨论记录了千都世角色包 `char_2d_14401.unity3d` 的社区样例，
  并展示了模型、贴图和 motions 的处理方式。该贴文同时说明部分背景/表情由 Unity
  Animator 控制，而非 Spine，因此不能直接套用蓝档 Spine 运行时。

## 资源池判断

目前未找到像蓝档 Kivo/主线资源池那样稳定、结构化、可直接纳入生产的千都世资源池。

- 官方网站适合获取角色名、宣传图和公开介绍，不提供可直接用于壁纸的 Live2D 模型、动作、
  语音批量接口或再分发许可证。
- `MaaStellaSora` 是开源自动化助手，可证明游戏有持续的社区工具维护，但它不是角色资源库，
  README 也将项目标为预览版。
- 社区提取讨论、网盘和视频分享可以作为研究线索，但文件来源、版本、完整性和再分发权利
  不稳定。尤其不能把“可以解包”推断为“可以公开上传或随壁纸分发”。

## 对本项目的直接影响

1. 先保留蓝档运行时的壳、日志、宿主回调和设置接入，使用资源待补齐预览验证 Web/WE 生命周期。
2. 等人工准备千都世 Live2D/Unity 资源后，先确认模型格式、动作命名、贴图和表情控制方式。
3. 真实模型接入前，需要新增 Live2D 适配层，或将合法获得的资源转换为当前运行时支持的格式；
   不应仅修改角色配置把 `.moc3` 当作 `.skel` 使用。
4. 语音和对话应以可核验的游戏内事件 ID 与授权资源为准，不在配置中臆造台词。
